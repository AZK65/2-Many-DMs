# Omni CRM project instructions

For every user-visible feature, UI addition, or UI change in this repository, read and follow [`.agents/skills/omni-ui-ux/SKILL.md`](.agents/skills/omni-ui-ux/SKILL.md) before editing. Treat its interface review and verification requirements as part of the task, even when the request sounds small.

Keep shared product changes aligned with the companion product repository. Port reviewed code changes, never private Git history, work-specific integrations, credentials, sessions, customer data, or personal screenshots. Preserve product-specific differences and run `npm run privacy:check` before publishing this public repository.
